# 파일 맵 (전체)

> **언제 읽나:** 어느 파일에 무엇이 있는지 찾을 때 읽는다. 코어 SKILL.md에는 디렉터리 수준 요약만 있다.
> 규칙만 적는다. 사연·실측 과정은 소스 파일 주석과 `docs/HISTORY.md`가 진다.
